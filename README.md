  - `WebSite` Schema with alternateNames (`World 777`, `World 777 Com`, `World 777 Online ID`, etc.)
  - `Organization` Schema
  - `FAQPage` Schema (ready for Google rich FAQ dropdowns)

- **Interactive In-Browser SEO Manager**: Click the **"SEO Manager"** button in the header or floating button to view real-time Google SERP preview, OpenGraph social card preview, target keywords, and copyable JSON-LD code.
